## 🇬🇧 English

### About

**Sogogi Shabu & Grill Buaran** is a Korean AYCE (All You Can Eat) restaurant located in Duren Sawit, East Jakarta. This landing page was created to showcase their menu, promotions, gallery, and reservation system in a modern, responsive single-page website featuring **24 interactive features**.

### What Makes This Special

This website was **not manually coded**. It was **built entirely through AI automation**:

- **Codebuff CLI** — An AI-powered CLI tool that understands codebases, writes code, runs commands, and iterates based on user feedback.
- **Ruflo** — A plugin ecosystem providing structured methodologies (SPARC), agent coordination (Swarm), workflows, and browser automation.
- **DeepSeek v4 Flash** — The AI model powering the agent, enabling fast, context-aware code generation.

Every single line of HTML, CSS, and JavaScript was generated, refined, and optimized through natural language conversation with the AI agent.

### Interactive Effects

- **3D Tilt Cards** — Menu and perk cards tilt on mouse hover
- **Magnetic Buttons** — CTA buttons follow cursor movement
- **Smooth Parallax** — rAF-based parallax with adaptive lerp interpolation
- **Scroll Reveal** — Intersection Observer fade-in animations
- **Scroll Progress Bar** — Top gradient progress indicator
- **Back to Top** — Smooth-scroll button with hover glow
- **Floating Food Particles** — 10 decorative emoji particles
- **Button Shimmer** — Animated shimmer effect on primary CTA

## 🚀 Getting Started / Memulai

Simply open `index.html` in any modern browser:

```bash
# Open directly (local file)
start index.html       # Windows
open index.html        # macOS
xdg-open index.html    # Linux

# Or serve locally for full CORS-free experience
python -m http.server 8080
```
