## 🇬🇧 English

### About

**Sogogi Shabu & Grill Buaran** is a Korean AYCE (All You Can Eat) restaurant located in Duren Sawit, East Jakarta. This landing page was created to showcase their menu, promotions, gallery, and reservation system in a modern, responsive single-page website.

### What Makes This Special

This website was **not manually coded**. It was **built entirely through AI automation**:

- **Codebuff CLI** — An AI-powered CLI tool (similar to Claude Code) that understands codebases, writes code, runs commands, and iterates based on user feedback.
- **Ruflo** — A plugin ecosystem that provides structured methodologies (SPARC), agent coordination (Swarm), workflows, and browser automation capabilities.
- **DeepSeek v4 Flash** — The AI model powering the agent, enabling fast, context-aware code generation and modification.

Every single line of HTML, CSS, and JavaScript was generated, refined, and optimized through natural language conversation with the AI agent — from initial layout to responsive images, parallax effects, dark mode, and form validation.

## ✨ Features / Fitur

### Interactive / Interaktif
- **3D Tilt Cards** — Menu and perk cards tilt on mouse hover
- **Magnetic Buttons** — CTA buttons follow cursor movement
- **Parallax Hero** — Smooth, GPU-accelerated parallax with requestAnimationFrame
- **Typewriter Effect** — Animated text in hero heading
- **Scroll Reveal** — Fade-in animations triggered by Intersection Observer
- **Scroll Progress Bar** — Top progress indicator on scroll
- **Back to Top** — Smooth-scroll button after scrolling down
- **Floating Food Particles** — Decorative emoji float animations

### Performance / Kinerja
- ⚡ **Responsive Images** — WebP primary + JPEG fallback with `srcset` (480w–1200w)
- ⚡ **Lazy Loading** — Native `loading="lazy"` + `decoding="async"`
- ⚡ **GPU Compositing** — `translateZ(0)` and `will-change` on animated elements
- ⚡ **Content Visibility** — `content-visibility: auto` on off-screen images
- ⚡ **Preconnect** — Font preconnect for faster font loading

### Accessibility / Aksesibilitas
- Semantic HTML with proper heading hierarchy
- ARIA labels on interactive elements
- Keyboard-navigable carousel and lightbox
- High contrast ratio in both light and dark themes
- Focus management for modal dialogs

## 🤖 How It Was Built / Cara Pembuatan

### The AI Workflow / Alur Kerja AI

```
User Prompt → Codebuff CLI (DeepSeek v4 Flash)
                    │
                    ▼
         ┌─────────────────────┐
         │     Context         │
         │    Gathering        │ ← Reads project files, analyzes structure
         └─────────┬───────────┘
                   ▼
         ┌─────────────────────┐
         │  Planning (SPARC)   │ ← Specification → Pseudocode → Architecture
         └─────────┬───────────┘
                   ▼
         ┌─────────────────────┐
         │  Agent Swarm        │ ← File-pickers, code-searchers, bashers
         │  Coordination       │ ← Researchers, browser automation
         └─────────┬───────────┘
                   ▼
         ┌─────────────────────┐
         │  Implementation     │ ← Code generation with str_replace/write_file
         │  + Validation       │ ← Testing, review, type-checking
         └─────────┬───────────┘
                   ▼
         ┌─────────────────────┐
         │  Review &           │ ← Code reviewer agents catch bugs
         │  Iterate            │ ← Browser automation validates output
         └─────────────────────┘
```
